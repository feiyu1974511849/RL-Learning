# 实验 1：单次 K 臂老虎机实验

**对应代码：** `01_bandit_single.py`

## 1. 实验目标

本实验是整个多臂老虎机代码实践的起点，目标是建立一个完整但简单的 K
臂老虎机交互过程，并观察 ε-贪心策略在一次具体实验中的学习过程。

主要验证以下过程能够正确运行：

``` text
Agent 选择动作
    ↓
Environment 返回 Reward
    ↓
Agent 更新动作价值估计 Q(a)
    ↓
继续选择动作
```

同时观察 Agent 的估计值 (Q(a)) 是否能够逐渐反映真实动作价值 (q\_\*(a))。

## 2. 实验内容

实验建立一个 10 臂老虎机。每个动作具有一个 Agent 不知道的真实动作价值
(q\_\*(a))。

Agent 使用：

-   ε-贪心策略（ε-Greedy Policy）选择动作；
-   样本平均法（Sample-Average Method）更新 (Q(a))；
-   (N(a)) 记录每个动作被选择的次数。

实验运行 1000 个时间步，最后输出：

-   每个动作的真实动作价值 (q\_\*(a))；
-   Agent 最终估计的 (Q(a))；
-   每个动作的选择次数 (N(a))；
-   真实最优动作；
-   Agent 估计的最优动作；
-   最优动作选择比例。

## 3. 实验结果与分析

一次实际运行得到：

``` text
真实最优动作：6
Agent 估计的最优动作：3
最优动作选择比例：2.20%
```

其中真实价值较高的两个动作约为：

``` text
q*(3) = 1.5230
q*(6) = 1.5792
```

真实最优动作是 6，但 Agent 最终认为动作 3 最好。

这个结果说明单次 Bandit 实验具有明显的随机性。即使动作 6
的真实价值最高，也不能保证它在有限次采样中始终产生更高的 Reward。

如果早期某个次优动作偶然获得较高 Reward，它的 (Q(a)) 就可能被高估；随后
ε-greedy
的利用阶段又会更多选择这个动作，从而进一步减少其他动作被尝试的机会。

因此，更换随机种子后，最终结果可能发生明显变化。

## 4. 实验结论

-   (Q(a)) 是对 (q\_\*(a)) 的估计，两者在有限时间内不一定完全一致。
-   单次 Reward 带有随机噪声，不能通过一次 Reward 判断动作真实价值。
-   单次实验容易受到随机种子和早期随机 Reward 的影响。
-   只观察一次运行不足以可靠评价一个随机算法。

因此，下一个实验需要通过大量独立运行降低单次实验的偶然性。

# 实验 2：多次独立 Bandit 实验

**对应代码：** `02_bandit_multiple_runs.py`

## 1. 实验目标

实验 1 表明，单次 Bandit 的结果可能具有很强的偶然性。

因此本实验的目标是：

> 通过大量相互独立的 Bandit
> 实验，对算法在每个时间步的表现进行统计平均，从而得到更加稳定、可靠的性能评价。

同时引入后续 Bandit 实验中最常用的两个评价指标：

-   Average Reward；
-   Optimal Action Rate。

## 2. 实验内容

实验不再只创建一个 Bandit，而是运行约：

``` text
2000 independent runs
×
1000 steps
```

每一个 run 都重新创建：

-   一个新的 10 臂老虎机；
-   一组新的真实动作价值；
-   一个新的 Agent；
-   一条独立的交互轨迹。

然后对所有 run 在相同 step 上的结果求平均。

最终绘制两条随时间变化的曲线：

1.  **Average Reward**：每一个时间步的平均奖励；
2.  **Optimal Action Rate**：每一个时间步选择真实最优动作的实验比例。

## 3. 实验结果与分析

在 (`\epsilon=0.1`{=tex}) 的实验中，可以观察到：

-   Average Reward 在前期快速上升；
-   随着训练继续，Average Reward 逐渐稳定在约 1.4；
-   Optimal Action Rate 从初期较低水平逐渐提高；
-   到实验后期，Optimal Action Rate 大约达到 80%。

相比实验 1 的单次运行，多次独立实验得到的曲线明显更加稳定。

Average Reward 上升说明 Agent 逐渐倾向于选择具有较高真实价值的动作。

Optimal Action Rate 上升则说明随着各动作被不断尝试，(Q(a))
的估计逐渐改善，Agent 找到真实最优动作的概率越来越高。

但最终 Optimal Action Rate 并没有达到 100%。一个重要原因是
(`\epsilon=0.1`{=tex}) 的 Agent
会持续进行随机探索，即使已经掌握了较好的动作，也不会永远只执行 greedy
action。

## 4. 实验结论

-   多次独立实验能够有效降低单次随机轨迹带来的偶然性。
-   Average Reward 可以反映 Agent 实际获得奖励的能力。
-   Optimal Action Rate 可以反映 Agent 找到真实最优动作的能力。
-   两个指标关注的问题不同，后续实验应结合观察。
-   后续 Bandit
    算法比较应主要采用多次独立实验，而不是依赖某一个随机种子的单次结果。

# 实验 3：不同探索率 ε 的对比实验

**对应代码：** `03_bandit_epsilon_comparison.py`

## 1. 实验目标

本实验研究 ε-贪心策略中探索率 (`\epsilon`{=tex}) 对学习效果的影响。

主要回答两个问题：

1.  完全不探索会发生什么？
2.  增加探索是否能够帮助 Agent 更好地找到真实最优动作？

通过控制其他条件不变，只改变
(`\epsilon`{=tex})，观察探索与利用之间的关系。

## 2. 实验内容

分别测试：

$$
\epsilon=0,\qquad \epsilon=0.01,\qquad \epsilon=0.1
$$

其中：

-   (`\epsilon=0`{=tex})：纯 greedy，不进行 ε-greedy 的随机探索；
-   (`\epsilon=0.01`{=tex})：进行少量探索；
-   (`\epsilon=0.1`{=tex})：进行更充分的探索。

每种策略均运行大量独立 Bandit 实验。

为了直观比较，将三个 (`\epsilon`{=tex}) 的结果分别绘制在同一张 Average
Reward 图和同一张 Optimal Action Rate 图中。

## 3. 实验结果与分析

最终实验结果为：

``` text
epsilon=0.0  | Average Reward=1.0863 | Optimal Action=36.65%
epsilon=0.01 | Average Reward=1.3102 | Optimal Action=61.00%
epsilon=0.1  | Average Reward=1.4184 | Optimal Action=80.65%
```

### ε = 0

纯 greedy 在前期学习后很快进入相对稳定状态，但 Optimal Action Rate
最终只有约 36.65%。

原因是 Agent 在训练早期对动作的认识非常有限。如果某个次优动作因为随机
Reward 暂时具有较大的 (Q(a))，greedy 会继续选择这个动作。

由于没有探索机制，其他动作可能长期得不到充分尝试，Agent
因而难以纠正早期的错误判断。

### ε = 0.01

加入少量探索后，Optimal Action Rate 上升到约 61%。

说明即使探索概率很低，Agent
也获得了重新尝试其他动作的机会，因此能够逐渐纠正一部分早期错误。

但是由于探索发生得比较少，发现真正高价值动作的速度仍然较慢。

### ε = 0.1

在当前实验条件下，(`\epsilon=0.1`{=tex}) 表现最好：

``` text
Average Reward = 1.4184
Optimal Action = 80.65%
```

更充分的探索使 Agent
能够更快获得不同动作的信息，从而更加准确地识别高价值动作。

需要注意的是，这个实验不能推出"(`\epsilon`{=tex})
越大越好"。如果探索概率继续增大，Agent
即使已经知道哪个动作较好，也会频繁执行随机动作，从而损失 Reward。

## 4. 实验结论

-   完全不探索容易使 Agent 因早期随机误差而停留在次优动作。
-   少量探索能够帮助 Agent 修正错误估计。
-   当前实验设置下，(`\epsilon=0.1`{=tex}) 明显优于 (`\epsilon=0`{=tex})
    和 (`\epsilon=0.01`{=tex})。
-   探索能够获得信息，但也会产生当前 Reward 的机会成本。
-   实验直观验证了探索与利用权衡（Exploration-Exploitation Trade-off）。

# 实验 4：乐观初始值实验

**对应代码：** `04_bandit_optimistic.py`

## 1. 实验目标

前面的 ε-greedy 通过随机选择动作实现探索。

本实验研究另一种探索方式：

> 如果不使用 ε-greedy
> 的随机探索，而是故意把未知动作的初始价值估计得很高，纯 greedy
> 是否也会主动尝试不同动作？

因此比较普通 ε-greedy 和乐观初始值（Optimistic Initial Values）策略。

## 2. 实验内容

实验比较两种 Agent。

普通 ε-greedy：

$$
Q_0(a)=0,\qquad \epsilon=0.1
$$

乐观 greedy：

$$
Q_0(a)=5,\qquad \epsilon=0
$$

两种 Agent 均使用固定步长：

$$
\alpha=0.1
$$

然后比较：

-   Average Reward；
-   Optimal Action Rate。

## 3. 实验结果与分析

从实际曲线可以观察到一个很明显的现象：

> Optimistic Greedy 前期表现较差、波动较大，但中后期逐渐超过普通
> ε-greedy。

原因是乐观 Agent 一开始认为所有动作都非常好：

$$
Q_0(a)=5
$$

某个动作被尝试后，如果实际 Reward 明显低于 5，它的估计值就会下降。

此时其他尚未充分尝试的动作仍然保持较高估计，因此 greedy 会转而尝试它们。

所以虽然：

$$
\epsilon=0
$$

Agent 仍然产生了明显的探索行为。

前期大量尝试未知动作会暂时降低 Average
Reward，但随着所有动作逐渐被探索，Agent 能够找到真正具有较高价值的动作。

在实验后期，Optimistic Greedy 的 Average Reward 和 Optimal Action Rate
均超过普通 (`\epsilon=0.1`{=tex}) 的 ε-greedy。

原因之一是普通 ε-greedy 会始终保留 10%
的随机探索，而乐观初始值带来的探索主要发生在训练早期。后期乐观估计逐渐消失后，greedy
可以更加集中地利用已经发现的高价值动作。

此外，实验前期出现了一些明显波动。这与 `np.argmax()`
在多个动作估计值相同时总是返回第一个最大值有关，会造成一定的动作选择同步现象。

## 4. 实验结论

-   探索并不一定必须通过随机选择动作实现。
-   乐观初始值能够让纯 greedy Agent 主动尝试尚未充分探索的动作。
-   乐观初始值的探索主要发生在训练早期。
-   当前平稳 Bandit 实验中，Optimistic Greedy 后期表现优于持续使用
    (`\epsilon=0.1`{=tex}) 的 ε-greedy。
-   乐观初始值依赖"初始的乐观"，当环境在后期发生变化时，它没有天然机制重新产生这种探索动力。

这进一步引出了非平稳环境问题。

# 实验 5：非平稳 Bandit 实验

**对应代码：** `05_bandit_nonstationary.py`

## 1. 实验目标

前面的实验中，各动作的真实动作价值在一次实验开始后保持不变，属于平稳问题。

本实验将环境修改为非平稳环境，让真实动作价值随着时间不断变化，并比较：

-   样本平均法（Sample Average）；
-   固定步长法（Constant Step Size）。

实验主要验证：

> 当环境持续变化时，更重视近期经验的固定步长方法是否能够比样本平均法更好地跟踪当前环境。

## 2. 实验内容

所有动作的真实动作价值从 0 开始，并在每一个时间步进行随机游走：

$$
q_{*,t+1}(a)=q_{*,t}(a)+\eta_t(a)
$$

其中随机变化的标准差为：

$$
\sigma=0.01
$$

两种 Agent 都使用：

$$
\epsilon=0.1
$$

区别只在价值更新方法。

### Sample Average

$$
Q(a)\leftarrow Q(a)+\frac1{N(a)}[R-Q(a)]
$$

### Constant Step Size

$$
Q(a)\leftarrow Q(a)+0.1[R-Q(a)]
$$

实验运行：

``` text
2000 runs
10000 steps
```

并比较两种方法的 Average Reward 和 Optimal Action Rate。

## 3. 实验结果与分析

从 Average Reward
曲线可以看到，两种方法的奖励都随着实验进行而总体上升，但固定步长方法很快超过
Sample Average，并在之后一直保持明显优势。

到实验后期，从曲线大致观察：

``` text
Sample Average       ≈ 1.10
Constant Step Size   ≈ 1.35
```

更明显的差距出现在 Optimal Action Rate。

实验后期大约为：

``` text
Sample Average       ≈ 45%～46%
Constant Step Size   ≈ 75%～77%
```

说明固定步长 Agent 明显更容易找到**当前时刻**真正最优的动作。

### 为什么 Sample Average 表现较差？

Sample Average 会长期保留所有历史 Reward 的影响。

但非平稳环境中的真实动作价值一直在变化，因此几千步以前的 Reward
反映的是"过去的环境"，未必还能准确描述当前动作价值。

而且随着动作被选择次数增加：

$$
\frac1{N(a)}\rightarrow0
$$

新 Reward 对 (Q(a)) 的影响越来越小，因此 Agent
对环境变化的响应越来越慢。

### 为什么 Constant Step Size 更好？

固定步长始终使用：

$$
\alpha=0.1
$$

不会因为训练时间变长而逐渐停止更新。

同时，固定步长会让旧 Reward 的影响随时间指数衰减，因此更重视近期数据。

这使它能够更快跟踪不断变化的：

$$
q_{*,t}(a)
$$

因此获得更高的 Optimal Action Rate 和 Average Reward。

### 曲线开始位置为什么出现异常尖峰？

Optimal Action Rate 图最开始出现了接近 90% 的尖峰。

这并不表示 Agent 在第一步就学会了最优动作。

实验初始化时：

$$
q_{*,0}(0)=q_{*,0}(1)=\cdots=q_{*,0}(9)=0
$$

所有动作都是真实并列最优。

同时 Agent 的 (Q(a)) 也全部相同。

`np.argmax()` 遇到并列最大值时会返回第一个最大值，因此环境的"最优动作"和
Agent 的 greedy 动作在初始时刻都倾向于 action 0，从而人为产生较高的
Optimal Action Rate。

这个尖峰属于实现细节导致的统计现象，而不是学习效果。

## 4. 实验结论

-   非平稳环境中，Agent 不仅需要学习，还需要持续适应环境变化。
-   Sample Average
    对全部历史经验长期保留较强影响，因此对变化中的环境响应较慢。
-   Constant Step Size 更重视近期经验，能够更好地跟踪当前真实动作价值。
-   当前实验中，固定步长在 Average Reward 和 Optimal Action Rate
    两项指标上都明显优于样本平均法。
-   实验验证了固定步长适合非平稳问题的核心原因：**旧经验影响逐渐衰减，新经验始终能够有效修改当前估计。**

# 实验 6：置信上界（UCB）与 ε-Greedy 对比

**对应代码：** `06_bandit_ucb.py`

## 1. 实验目标

前面的实验已经发现：ε-Greedy 能够通过随机探索避免纯 Greedy 长期陷入次优动作，但随机探索时不会主动区分哪些动作更不确定。本实验引入置信上界（Upper Confidence Bound, UCB），检验基于价值估计和探索奖励的动作选择方法在平稳环境中的表现，并研究探索系数 $c$ 对探索与利用的影响。

具体比较四组算法在 Average Reward 和 Optimal Action Rate 上的差别，观察 UCB 初期探索行为和训练后期的性能。

## 2. 实验内容

采用 10-Armed Stationary Bandit，每次运行先生成各动作真实价值 $q_*(a)\sim\mathcal N(0,1)$，采样奖励 $R_t\sim\mathcal N(q_*(A_t),1)$；单次运行期间真实动作价值不变。

- 独立实验次数：2000 runs；每次运行 1000 steps。
- ε-Greedy 基线：$\epsilon=0.1$。
- UCB 对比：$c=1,2,4$。
- 价值估计更新：全部使用 Sample Average。
- UCB 对未访问动作先进行一次探索，再根据 $Q_t(a)+c\sqrt{\ln t/N_t(a)}$ 评分选择。
- 所有方法共用相同的一批真实动作价值数组，策略和奖励采样使用各自随机流。
- 在每一个 step 对全部 runs 求平均，绘制 Average Reward 与 Optimal Action Rate 曲线；代码另打印最后 100 步的平均指标。

## 3. 实验结果与分析

用户提供的两幅实验曲线显示，训练接近第 1000 步时，结果大致为：

| 策略 | Average Reward（约） | Optimal Action Rate（约） |
|---|---:|---:|
| UCB（$c=1$） | 1.54 | 93% |
| UCB（$c=2$） | 1.50 | 87% |
| ε-Greedy（$\epsilon=0.1$） | 1.40 | 81% |
| UCB（$c=4$） | 1.38 | 71% |

**说明：这些数字是根据上传曲线末端位置读出的近似值，并不是控制台最后 100 步输出的精确统计；精确数值需以终端输出为准。**

### UCB（c=1）为何表现较好？

橙色曲线早期迅速上升，后期 Average Reward 维持在约 1.5 以上，Optimal Action Rate 接近 93%。在本次平稳环境与 1000 步预算内，较小的探索奖励让 Agent 在收集一定信息后更重视当前高价值动作，探索与利用取得了较好的平衡。

### 为什么 c=4 反而不如 ε-Greedy？

$c$ 增大后，尚未充分采样动作的探索加分更大，即使某个动作当前估计价值较低，Agent 也可能继续选择它。红色曲线提升较慢，实验末端平均奖励和最优动作选择率在四组中最低。说明**增加探索强度具有机会成本，探索系数并非越大越好**。

### 为什么两个指标的排序基本相同？

当前实验中，更常选择真实最优动作的 Agent 通常也能获得较高的平均奖励，因此两图趋势一致。不过两个指标并不等价：一个次优动作如果与最优动作价值很接近，可能产生较高奖励但仍不计入 Optimal Action Rate。

### 为什么 ε-Greedy 没有达到 91%？

当 $\epsilon=0.1,k=10$ 且 Agent 的 Greedy 动作已经是真实最优动作时，下一次选择真实最优动作的概率为 $(1-\epsilon)+\epsilon/k=91\%$。实际曲线后期约 81%，原因是并非所有独立运行都已正确识别最优动作，并且算法仍在进行随机探索。91% 不是实验曲线必然达到的水平。

### 初期曲线为什么有明显变化？

UCB 初始化时先让每个动作至少被选择一次，10 个动作会在前 10 步得到初始采样。从后续步骤才开始正常计算 UCB 分数；不同真实动作价值与随机奖励使早期曲线出现变化。初始 10 步中 $c$ 不参与动作选择，因此不同 $c$ 曲线的微小差异主要来自随机采样，不代表某个 $c$ 在尚未启用时就产生优势。

## 4. 实验结论

- UCB 不只利用 $Q_t(a)$，还用访问次数相关的探索奖励优先考虑不确定性更高的动作，从而实现有针对性的探索。
- 在当前 10-Armed 平稳高斯 Bandit、2000 runs × 1000 steps 的实验条件下，$c=1$ 的效果最好，$c=2$ 次之，$c=4$ 甚至不如 ε-Greedy（$\epsilon=0.1$）。
- $c$ 越大通常意味着探索倾向越强，但不代表 Average Reward 或 Optimal Action Rate 一定更高。
- 最优动作选择率评价的是**实际执行最优动作的频率**，并不直接测量 Agent 是否已经在价值估计中正确识别最优动作。
- 结果适用于本次特定实验，不说明 UCB 总是优于 ε-Greedy，也不能将经典 UCB 直接视为适合非平稳环境。
