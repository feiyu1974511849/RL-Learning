# 1. 多臂老虎机问题

## 1.1 基本问题

多臂老虎机（Multi-Armed Bandit, MAB）是强化学习中最基础的决策问题之一。

假设环境提供 (k) 个动作：

$$
\mathcal A=\{0,1,\ldots,k-1\}
$$

在每一个时间步 (t)：

1.  Agent 选择一个动作 (A_t)；
2.  Environment 根据该动作产生一个奖励 (R_t)；
3.  Agent 根据获得的奖励更新自己对该动作的认识；
4.  进入下一个时间步。

可以写成：

$$
A_t\rightarrow R_t\rightarrow \text{Update}\rightarrow A_{t+1}
$$

Bandit 与后面要学习的完整强化学习问题有一个重要区别：

> 当前暂时没有考虑状态（State）以及状态转移。

因此这里主要研究：

$$
\boxed{\text{在多个动作之间应该如何进行选择？}}
$$

这个简单问题会直接引出强化学习中的核心矛盾：

$$
\boxed{\text{探索（Exploration）与利用（Exploitation）的权衡}}
$$

------------------------------------------------------------------------

# 2. 真实动作价值、奖励和动作价值估计

## 2.1 真实动作价值 (q\_\*(a))

动作 (a) 的真实动作价值（True Action Value）定义为：

$$
\boxed{q_*(a)=\mathbb E[R_t\mid A_t=a]}
$$

含义是：

> 在选择动作 (a) 的条件下，能够获得的 Reward 的期望。

例如：

$$
q_*(a)=1.5
$$

不是说每一次选择动作 (a) 都一定获得：

$$
R=1.5
$$

而是说如果反复执行这个动作，长期平均 Reward 会趋近于 1.5。

在我们的 10 臂老虎机实验中，通常首先生成：

$$
q_*(a)\sim\mathcal N(0,1)
$$

然后当 Agent 选择动作 (a) 时：

$$
R_t\sim\mathcal N(q_*(a),1)
$$

因此：

$$
\mathbb E[R_t\mid A_t=a]=q_*(a)
$$

------------------------------------------------------------------------

## 2.2 为什么 Reward 每次可以不同？

假设：

$$
q_*(a)=1.5
$$

但：

$$
R_t\sim\mathcal N(1.5,1)
$$

那么连续选择这个动作可能得到：

``` text
0.7
2.1
1.3
3.0
0.9
...
```

这些 Reward 都不同，但它们背后的期望仍然是：

$$
1.5
$$

因此必须记住：

$$
\boxed{\text{单次 Reward 不等于真实动作价值}}
$$

------------------------------------------------------------------------

## 2.3 Agent 为什么不知道 (q\_\*(a))？

如果 Agent 可以直接看到：

$$
q_*(0),q_*(1),\ldots,q_*(k-1)
$$

那么问题就没有学习的必要了。

直接选择：

$$
a_*=\arg\max_a q_*(a)
$$

即可。

真正的问题是：

> 环境知道真实动作价值，但 Agent 不知道。

Agent 只能通过不断执行动作并观察：

$$
R_t
$$

来推测：

$$
q_*(a)
$$

------------------------------------------------------------------------

## 2.4 动作价值估计 (Q_t(a))

Agent 对动作价值的估计记为：

$$
\boxed{Q_t(a)}
$$

我们希望：

$$
Q_t(a)\approx q_*(a)
$$

其中：

-   (q\_\*(a))：环境中的真实值；
-   (Q_t(a))：Agent 根据经验得到的估计值。

学习过程可以理解为：

$$
R_1,R_2,\ldots,R_t
\longrightarrow
Q_t(a)
\longrightarrow
q_*(a)
$$

------------------------------------------------------------------------

## 2.5 三个量必须严格区分

### (q\_\*(a))：真实动作价值

属于环境：

$$
q_*(a)=\mathbb E[R_t\mid A_t=a]
$$

### (R_t)：实际奖励

Agent 在第 (t) 步真正观察到的随机样本。

### (Q_t(a))：动作价值估计

Agent 根据过去经验形成的估计：

$$
Q_t(a)\approx q_*(a)
$$

因此：

$$
\boxed{q_*(a)\neq R_t\neq Q_t(a)}
$$

虽然它们彼此相关，但含义完全不同。

------------------------------------------------------------------------

# 3. 最优动作

真实最优动作（Optimal Action）定义为：

$$
\boxed{a_*=\arg\max_a q_*(a)}
$$

但是 Agent 看不到 (q\_\*(a))，因此不能直接计算这个动作。

Agent 能够计算的是：

$$
\boxed{\arg\max_a Q_t(a)}
$$

如果：

$$
\arg\max_aQ_t(a)=\arg\max_aq_*(a)
$$

说明 Agent 当前正确识别出了真实最优动作。

这也是后面 Optimal Action Rate 指标的基础。

------------------------------------------------------------------------

# 4. 样本平均法（Sample-Average Method）

## 4.1 基本思想

假设动作 (a) 已经被选择了 (n) 次，得到：

$$
R_1,R_2,\ldots,R_n
$$

一个自然的估计方法是求平均：

$$
\boxed{
Q_n(a)=\frac{R_1+R_2+\cdots+R_n}{n}
}
$$

也就是：

$$
\boxed{
Q_n(a)=\frac1n\sum_{i=1}^{n}R_i
}
$$

这就是样本平均法。

------------------------------------------------------------------------

# 5. 样本平均增量公式推导

如果每获得一个新的 Reward 都重新计算：

$$
\frac{R_1+\cdots+R_n}{n}
$$

就需要保存全部历史 Reward。

实际上没有必要。

假设已经有：

$$
Q_n=\frac1n\sum_{i=1}^{n}R_i
$$

现在获得一个新的：

$$
R_{n+1}
$$

则：

$$
Q_{n+1}
=
\frac1{n+1}\sum_{i=1}^{n+1}R_i
$$

拆开最后一个 Reward：

$$
Q_{n+1}
=
\frac1{n+1}
\left(
\sum_{i=1}^{n}R_i+R_{n+1}
\right)
$$

因为：

$$
\sum_{i=1}^{n}R_i=nQ_n
$$

所以：

$$
Q_{n+1}
=
\frac{nQ_n+R_{n+1}}{n+1}
$$

进一步：

$$
Q_{n+1}
=
\frac{n+1}{n+1}Q_n
-\frac1{n+1}Q_n
+\frac1{n+1}R_{n+1}
$$

于是：

$$
Q_{n+1}
=
Q_n+\frac1{n+1}(R_{n+1}-Q_n)
$$

因此得到增量更新公式：

$$
\boxed{
Q_{n+1}
=
Q_n+\frac1{n+1}(R_{n+1}-Q_n)
}
$$

在代码中通常使用动作访问次数 (N(a))：

$$
\boxed{
Q(a)\leftarrow Q(a)+\frac1{N(a)}[R-Q(a)]
}
$$

对应：

``` python
action_counts[action] += 1
q_values[action] += (
    reward - q_values[action]
) / action_counts[action]
```

------------------------------------------------------------------------

# 6. 一个非常重要的统一更新结构

样本平均增量公式可以写成：

$$
Q_{\text{new}}
=
Q_{\text{old}}
+
\alpha
\left(
\text{Target}-Q_{\text{old}}
\right)
$$

其中样本平均法：

$$
\alpha=\frac1{N(a)}
$$

而：

$$
R-Q(a)
$$

表示：

> 新观察到的结果与当前估计之间的误差。

因此可以记成：

$$
\boxed{
\text{新估计}
=
\text{旧估计}
+
\text{步长}
\times
(\text{目标}-\text{旧估计})
}
$$

这个形式非常重要。

以后学习：

-   时序差分学习（Temporal-Difference Learning, TD）；
-   Q-learning；
-   SARSA；
-   DQN；

都会再次遇到类似的更新结构。

------------------------------------------------------------------------

# 7. 探索与利用

## 7.1 利用（Exploitation）

如果根据当前知识直接选择：

$$
\boxed{
A_t=\arg\max_aQ_t(a)
}
$$

称为利用。

直觉：

> 根据现在已经掌握的信息，选择目前看起来最好的动作。

优点是当前 Reward 往往较高。

问题是：

$$
Q_t(a)
$$

只是估计值，可能是错的。

------------------------------------------------------------------------

## 7.2 探索（Exploration）

探索表示：

> 尝试当前并不一定被认为最好的动作，以获得新的信息。

探索可能导致当前 Reward 降低，但能够：

-   获得尚未充分尝试动作的信息；
-   修正错误的 (Q(a))；
-   发现真正更好的动作；
-   提高未来决策质量。

因此：

$$
\boxed{
\text{探索可能牺牲当前收益，以换取未来更好的决策}
}
$$

------------------------------------------------------------------------

## 7.3 为什么不能只利用？

假设：

$$
q_*(0)=1.0,\qquad q_*(1)=2.0
$$

但因为早期 Reward 的随机性，Agent 暂时估计：

$$
Q(0)=1.4,\qquad Q(1)=0.7
$$

如果永远 greedy：

$$
A_t=\arg\max_aQ(a)
$$

那么 Agent 会持续选择动作 0。

动作 1 得不到新的采样：

$$
Q(1)
$$

也就没有机会被修正。

于是：

$$
\boxed{\text{错误估计可能通过纯利用被长期保留下来}}
$$

------------------------------------------------------------------------

# 8. ε-贪心策略（ε-Greedy Policy）

## 8.1 定义

ε-贪心策略：

$$
\boxed{
A_t=
\begin{cases}
\text{随机选择动作}, & \text{概率 }\epsilon\\
\arg\max_aQ_t(a), & \text{概率 }1-\epsilon
\end{cases}
}
$$

例如：

$$
\epsilon=0.1
$$

意味着：

-   90% 概率进入利用；
-   10% 概率进入探索。

代码：

``` python
if np.random.random() < epsilon:
    action = np.random.randint(k)
else:
    action = np.argmax(q_values)
```

------------------------------------------------------------------------

# 9. 为什么探索时不能先看看 Reward 再决定？

一个容易产生的想法是：

> 既然探索动作可能不好，那能不能先看看探索动作的
> Reward，如果比当前最好动作差，就不要选它？

不能。

因为环境的交互顺序是：

$$
\boxed{A_t\rightarrow R_t}
$$

Reward 是执行动作之后才产生的。

你无法在执行动作之前知道：

$$
R_t
$$

否则相当于提前知道环境结果。

而且即使某次探索获得较低 Reward：

$$
R_t<\text{当前某个动作的 Reward}
$$

也不能证明这个动作真实价值更低。

因为：

$$
R_t
$$

只是随机样本，而真正需要估计的是：

$$
q_*(a)=\mathbb E[R_t\mid A_t=a]
$$

------------------------------------------------------------------------

# 10. ε-greedy 中最优动作概率为什么可能是 91%？

假设：

-   有 10 个动作；
-   (`\epsilon=0.1`{=tex})；
-   Agent 已经正确知道哪个动作最好。

利用阶段概率：

$$
1-\epsilon=0.9
$$

这时一定选择最优动作。

探索阶段概率：

$$
\epsilon=0.1
$$

探索是从 10 个动作中随机选，因此仍然有：

$$
\frac1{10}
$$

概率碰巧选择最优动作。

所以：

$$
P(A_t=a_*)
=
(1-\epsilon)+\epsilon\frac1k
$$

代入：

$$
P(A_t=a_*)
=
0.9+0.1\times0.1
$$

得到：

$$
\boxed{
P(A_t=a_*)=0.91
}
$$

也就是 91%。

一般公式：

$$
\boxed{
P(A_t=a_*)=(1-\epsilon)+\frac{\epsilon}{k}
}
$$

但必须注意：

> 91% 的前提是 Agent 已经正确识别真实最优动作。

实际实验中的 Optimal Action Rate 不一定达到 91%。

------------------------------------------------------------------------

# 11. 随机种子（Random Seed）

计算机中的随机数通常是伪随机数。

使用：

``` python
np.random.seed(42)
```

可以固定后续随机数序列，使实验具有可复现性（Reproducibility）。

在 Bandit 中随机数会影响：

-   (q\_\*(a)) 的生成；
-   Reward 的采样；
-   是否触发探索；
-   探索时选择哪个动作；
-   后续整个学习轨迹。

因此不同 seed 可能产生完全不同的单次实验结果。

随机种子的正确用途是：

$$
\boxed{\text{保证实验能够复现}}
$$

而不是不断尝试 seed，挑一个算法表现最好的结果。

------------------------------------------------------------------------

# 12. 为什么需要多次独立实验？

单次实验受到随机性影响太大。

因此更合理的方法是：

$$
M\text{ runs}\times T\text{ steps}
$$

例如：

$$
2000\times1000
$$

每一个 run 都重新创建：

-   Environment；
-   真实动作价值；
-   Agent；
-   完整交互轨迹。

这样可以从统计意义上评价算法。

------------------------------------------------------------------------

# 13. Average Reward

假设有 (M) 个独立实验。

第 (i) 个实验在第 (t) 步获得：

$$
R_t^{(i)}
$$

那么第 (t) 步的平均奖励为：

$$
\boxed{
\bar R_t
=
\frac1M
\sum_{i=1}^{M}R_t^{(i)}
}
$$

它回答：

> 如果大量独立运行这个算法，第 (t) 步平均能获得多少 Reward？

NumPy 中如果：

``` python
rewards.shape == (runs, steps)
```

那么：

``` python
average_rewards = np.mean(rewards, axis=0)
```

表示对 run 这一维求平均，保留 step。

------------------------------------------------------------------------

# 14. Optimal Action Rate

定义指示变量：

$$
I_t^{(i)}
=
\begin{cases}
1,&A_t^{(i)}=a_*^{(i)}\\
0,&A_t^{(i)}\neq a_*^{(i)}
\end{cases}
$$

那么：

$$
\boxed{
\text{OptimalActionRate}_t
=
\frac1M\sum_{i=1}^{M}I_t^{(i)}
}
$$

例如：

$$
\text{OptimalActionRate}_{1000}=0.8
$$

表示：

> 在第 1000 步，2000 个独立实验中大约 80% 的 Agent
> 选择了各自环境中的真实最优动作。

Average Reward 和 Optimal Action Rate 不完全等价。

某个动作即使不是严格的最优动作，也可能和最优动作价值非常接近，因此：

-   Optimal Action Rate 较低；
-   Average Reward 仍可能不错。

所以实验中通常同时观察两个指标。

------------------------------------------------------------------------

# 15. 多次实验平均与移动平均的区别

多次独立实验平均：

$$
\frac1M\sum_{i=1}^{M}R_t^{(i)}
$$

是在**同一个时间步**对不同实验求平均。

移动平均（Moving Average）则是在一条时间序列内部，例如：

$$
\frac{R_{t-9}+\cdots+R_t}{10}
$$

用于平滑单条曲线。

二者解决的问题不同：

-   多次独立实验平均：降低不同实验之间的随机性；
-   移动平均：降低一条时间序列视觉上的短期波动。

------------------------------------------------------------------------

# 16. 不同 ε 的意义

我们实验比较过：

$$
\epsilon=0,\qquad0.01,\qquad0.1
$$

## 16.1 ε = 0

完全 greedy：

$$
A_t=\arg\max_aQ_t(a)
$$

早期估计一旦出现错误，就可能因为没有探索而长期无法修正。

因此：

$$
\boxed{\text{训练时间更长并不保证纯 greedy 一定找到最优动作}}
$$

如果策略不给某个动作采样机会，那么多出来的训练步数只是重复已有行为。

## 16.2 ε 较小

例如：

$$
\epsilon=0.01
$$

能够偶尔探索，从而修正部分错误，但探索速度较慢。

## 16.3 ε 较大

例如：

$$
\epsilon=0.1
$$

在当前实验中能够更快发现高价值动作。

但：

$$
\boxed{\epsilon\text{ 并不是越大越好}}
$$

极端情况下：

$$
\epsilon=1
$$

意味着完全随机选择动作，几乎不利用已经学到的信息。

所以核心仍然是：

$$
\boxed{\text{Exploration-Exploitation Trade-off}}
$$

------------------------------------------------------------------------

# 17. 乐观初始值（Optimistic Initial Values）

## 17.1 普通初始化

通常：

$$
Q_0(a)=0
$$

表示 Agent 初始时没有特别偏向某个动作。

## 17.2 乐观初始化

可以故意设置：

$$
\boxed{Q_0(a)=5}
$$

虽然真实动作价值通常远小于 5。

这里不是认为真实值就是 5，而是：

> 故意高估未知动作，让它们看起来值得尝试。

------------------------------------------------------------------------

# 18. 为什么乐观初始值可以产生探索？

假设三个动作：

$$
Q_0=[5,5,5]
$$

使用：

$$
\epsilon=0
$$

也就是纯 greedy。

第一次选择动作 0，假设 Reward 较低，更新后：

$$
Q=[4.6,5,5]
$$

那么下一次 greedy 会选择仍然为 5 的动作。

例如动作 1 更新后：

$$
Q=[4.6,4.4,5]
$$

接下来又会选择动作 2。

因此：

$$
\boxed{
\epsilon=0
\not\Rightarrow
\text{整个学习过程没有探索}
}
$$

更准确地说：

> (`\epsilon=0`{=tex}) 只表示没有 ε-greedy 中人为加入的随机探索。

乐观初始值本身就能够通过价值估计驱动探索。

------------------------------------------------------------------------

# 19. 为什么乐观初始值实验使用固定步长？

如果使用 Sample Average：

第一次访问某个动作时：

$$
N(a)=1
$$

于是：

$$
Q_{\text{new}}
=
Q_{\text{old}}
+
1(R-Q_{\text{old}})
$$

得到：

$$
Q_{\text{new}}=R
$$

也就是说：

$$
Q_0(a)=5
$$

第一次更新后会被完全覆盖。

而固定步长：

$$
Q_{\text{new}}
=
Q_{\text{old}}
+
\alpha(R-Q_{\text{old}})
$$

假设：

$$
Q_0=5,\qquad\alpha=0.1,\qquad R=1
$$

则：

$$
Q_1
=
5+0.1(1-5)
$$

$$
Q_1=5-0.4
$$

所以：

$$
\boxed{Q_1=4.6}
$$

乐观估计不会一次消失，而是逐渐被真实经验修正。

------------------------------------------------------------------------

# 20. 乐观初始值的局限

乐观初始值主要在训练开始阶段有效。

随着每个动作不断被尝试：

$$
Q_t(a)
$$

逐渐下降到更合理的范围。

一旦这种"初始乐观"被消耗掉，后面就不会自动恢复。

因此如果环境在训练后期发生变化：

> 原来很差的动作突然变好了。

Agent 并不会因为初始值曾经是 5 就重新产生强烈探索。

这引出了：

$$
\boxed{\text{平稳问题与非平稳问题}}
$$

------------------------------------------------------------------------

# 21. 平稳问题（Stationary Problem）

平稳环境不是：

$$
R_t=\text{constant}
$$

而是：

$$
\boxed{\text{Reward 背后的概率分布不随时间变化}}
$$

例如：

$$
q_*(a)=1.5
$$

始终不变：

$$
R_t\sim\mathcal N(1.5,1)
$$

可能：

$$
R_1=0.8,\quad
R_2=2.2,\quad
R_3=1.1
$$

虽然：

$$
R_1\neq R_2\neq R_3
$$

但：

$$
q_*(a)=1.5
$$

一直没有改变。

所以：

$$
\boxed{
R_t\text{ 可以变化}
\neq
q_*(a)\text{ 发生变化}
}
$$

这句话非常重要。

------------------------------------------------------------------------

# 22. 非平稳问题（Non-stationary Problem）

如果动作真实价值本身会随时间改变，就写成：

$$
\boxed{q_{*,t}(a)}
$$

例如：

$$
q_{*,1}(a)=1.0
$$

过了一段时间：

$$
q_{*,5000}(a)=2.3
$$

此时不是 Reward 围绕同一个均值随机波动，而是：

> Reward 背后的均值本身发生了变化。

因此：

$$
R_t\sim\mathcal N(q_{*,t}(a),1)
$$

中的：

$$
q_{*,t}(a)
$$

会随时间变化。

------------------------------------------------------------------------

# 23. 随机游走（Random Walk）

我们使用随机游走构造非平稳 Bandit：

$$
\boxed{
q_{*,t+1}(a)
=
q_{*,t}(a)+\eta_t(a)
}
$$

其中：

$$
\eta_t(a)\sim\mathcal N(0,\sigma^2)
$$

例如：

$$
\sigma=0.01
$$

表示每一步真实动作价值只发生一个较小的随机变化。

代码：

``` python
true_values += np.random.normal(
    loc=0.0,
    scale=random_walk_std,
    size=k,
)
```

注意：

> 每一步是所有动作的真实价值都进行随机游走，而不仅仅是当前被 Agent
> 选择的动作。

因为真实动作价值描述的是环境本身，而不是 Agent 是否观察了这个动作。

------------------------------------------------------------------------

# 24. Sample Average 为什么适合平稳环境？

假设真实动作价值始终：

$$
q_*(a)=1.5
$$

从第 1 次到第 10000 次采样，所有 Reward 都是在帮助估计同一个东西：

$$
q_*(a)=1.5
$$

因此旧数据并没有"过期"。

样本越多：

$$
Q_n(a)
=
\frac1n\sum_{i=1}^{n}R_i
$$

通常越能够抵消 Reward 的随机噪声。

所以在平稳环境中，保留全部历史数据是合理的。

------------------------------------------------------------------------

# 25. Sample Average 为什么难以跟踪非平稳环境？

假设某个动作早期：

$$
q_{*,t}(a)\approx1
$$

后来：

$$
q_{*,t}(a)\approx3
$$

当前真正关心的是：

$$
\boxed{\text{现在的 }q_{*,t}(a)}
$$

但是 Sample Average：

$$
Q_n
=
\frac1n
(R_1+R_2+\cdots+R_n)
$$

仍然把很久以前 (q\_*`\approx1`{=tex}) 时获得的 Reward 和最近
(q\_*`\approx3`{=tex}) 时获得的 Reward 一起平均。

因此旧数据会拖慢估计变化。

------------------------------------------------------------------------

# 26. 从步长角度理解 Sample Average 的问题

样本平均增量公式：

$$
Q_{n+1}
=
Q_n+\frac1{n+1}(R_{n+1}-Q_n)
$$

步长：

$$
\alpha_n=\frac1{n+1}
$$

随着：

$$
n\rightarrow\infty
$$

有：

$$
\boxed{\alpha_n\rightarrow0}
$$

例如：

$$
n=10\Rightarrow\alpha\approx0.1
$$

$$
n=100\Rightarrow\alpha\approx0.01
$$

$$
n=10000\Rightarrow\alpha\approx0.0001
$$

也就是说：

> Agent 学得越久，新 Reward 越难改变它已有的估计。

平稳环境中，这是稳定性的来源。

非平稳环境中，却会变成适应能力不足的问题。

------------------------------------------------------------------------

# 27. 固定步长（Constant Step Size）

解决思路是：

> 不让步长随着访问次数不断减小，而是始终使用固定的 (`\alpha`{=tex})。

更新：

$$
\boxed{
Q_{n+1}
=
Q_n+\alpha(R_n-Q_n)
}
$$

例如：

$$
\alpha=0.1
$$

无论已经学习：

-   10 次；
-   1000 次；
-   100000 次；

新 Reward 都仍然具有明显影响。

------------------------------------------------------------------------

# 28. 固定步长公式展开

从：

$$
Q_{n+1}
=
Q_n+\alpha(R_n-Q_n)
$$

开始。

展开：

$$
Q_{n+1}
=
Q_n+\alpha R_n-\alpha Q_n
$$

整理：

$$
\boxed{
Q_{n+1}
=
(1-\alpha)Q_n+\alpha R_n
}
$$

再把：

$$
Q_n=(1-\alpha)Q_{n-1}+\alpha R_{n-1}
$$

代入：

$$
Q_{n+1}
=
(1-\alpha)
[(1-\alpha)Q_{n-1}+\alpha R_{n-1}]
+\alpha R_n
$$

展开：

$$
Q_{n+1}
=
(1-\alpha)^2Q_{n-1}
+
\alpha(1-\alpha)R_{n-1}
+
\alpha R_n
$$

继续递归：

$$
Q_{n+1}
=
(1-\alpha)^3Q_{n-2}
+
\alpha(1-\alpha)^2R_{n-2}
+
\alpha(1-\alpha)R_{n-1}
+
\alpha R_n
$$

最终得到：

$$
\boxed{
Q_{n+1}
=
(1-\alpha)^nQ_1
+
\sum_{i=1}^{n}
\alpha(1-\alpha)^{n-i}R_i
}
$$

------------------------------------------------------------------------

# 29. 指数加权（Exponential Weighting）

上面的公式说明，最近 Reward 的权重是：

$$
R_n:\quad\alpha
$$

前一个：

$$
R_{n-1}:\quad\alpha(1-\alpha)
$$

再前一个：

$$
R_{n-2}:\quad\alpha(1-\alpha)^2
$$

一般地：

$$
\boxed{
R_{n-k}\text{ 的权重}
=
\alpha(1-\alpha)^k
}
$$

例如：

$$
\alpha=0.2
$$

那么：

$$
R_n:0.2
$$

$$
R_{n-1}:0.2\times0.8=0.16
$$

$$
R_{n-2}:0.2\times0.8^2=0.128
$$

$$
R_{n-3}:0.2\times0.8^3=0.1024
$$

所以越旧的数据权重越小。

这就是：

$$
\boxed{\text{指数加权（Exponential Weighting）}}
$$

------------------------------------------------------------------------

# 30. "遗忘旧数据"到底是什么意思？

固定步长并没有真正把旧 Reward 从内存里"删除"。

所谓遗忘是：

$$
\boxed{\text{旧 Reward 对当前 }Q\text{ 的影响越来越小}}
$$

因为：

$$
0<1-\alpha<1
$$

所以：

$$
(1-\alpha)^k\rightarrow0
$$

当 (k) 很大时，很久以前的数据权重接近 0。

因此固定步长更加关注：

$$
\boxed{\text{近期发生了什么}}
$$

而 Sample Average 更关注：

$$
\boxed{\text{整个历史平均发生了什么}}
$$

这正是两种方法在非平稳环境中表现不同的根本原因。

------------------------------------------------------------------------

# 31. α 的大小意味着什么？

固定步长：

$$
Q_{n+1}
=
Q_n+\alpha(R_n-Q_n)
$$

## 较小的 α

例如：

$$
\alpha=0.01
$$

特点：

-   每次更新幅度较小；
-   \(Q\) 更平滑；
-   对单次 Reward 噪声不敏感；
-   但跟踪环境变化较慢。

## 较大的 α

例如：

$$
\alpha=0.5
$$

特点：

-   新 Reward 影响很大；
-   能快速适应变化；
-   但也更容易被 Reward 的随机噪声影响。

因此：

$$
\boxed{
\alpha
\text{ 控制“适应速度”和“估计稳定性”之间的权衡}
}
$$

------------------------------------------------------------------------

# 32. Sample Average 与 Constant Step Size 对比

  对比项         Sample Average   Constant Step Size
  -------------- ---------------- -------------------------
  步长           (1/N(a))         固定 (`\alpha`{=tex})
  新数据影响     越来越小         始终存在
  旧数据影响     长期保留         指数衰减
  稳定性         较强             取决于 (`\alpha`{=tex})
  跟踪变化能力   较弱             较强
  更适合         平稳环境         非平稳环境

需要注意：

$$
\boxed{\text{Constant Step Size 并不是任何情况下都绝对优于 Sample Average}}
$$

关键是方法的性质是否与环境相匹配。

------------------------------------------------------------------------

# 33. 非平稳实验中时间顺序为什么重要？

代码中：

``` python
best_action = bandit.get_best_action()

action = agent.select_action()
reward = bandit.step(action)
```

必须先记录当前：

$$
a_{*,t}
$$

然后再调用：

``` python
bandit.step(action)
```

因为 `step()` 内部不仅返回 Reward，还会让真实动作价值发生随机游走。

如果先随机游走再计算 best action，那么实际上是在使用：

$$
a_{*,t+1}
$$

评价 Agent 在时间：

$$
t
$$

作出的决策。

也就是时间索引错位。

这一点后面学习马尔可夫决策过程（Markov Decision Process,
MDP）时会更加重要。

------------------------------------------------------------------------

# 34. Tie-Breaking：并列最大值处理

NumPy：

``` python
np.argmax(q_values)
```

遇到多个相同最大值时，返回第一个最大值的位置。

例如：

``` python
q_values = np.array([5.0, 5.0, 5.0])
np.argmax(q_values)
```

返回：

``` text
0
```

这意味着如果大量 Agent 都使用完全相同初始化：

$$
Q_0(0)=Q_0(1)=\cdots=Q_0(k-1)
$$

它们在初始阶段可能都会偏向 action 0。

这会产生人为的同步现象。

更严格的 Tie-Breaking 可以：

1.  找到所有最大值动作；
2.  从它们中随机选择一个。

例如：

``` python
max_value = np.max(q_values)
best_actions = np.flatnonzero(q_values == max_value)
action = np.random.choice(best_actions)
```

------------------------------------------------------------------------

# 35. 非平稳实验开头异常尖峰的原因

在非平稳 Bandit 中，我们初始化：

$$
q_{*,0}(a)=0
$$

因此所有动作一开始都是真实并列最优。

同时：

$$
Q_0(a)=0
$$

Agent 的所有动作也并列。

如果 Environment 和 Agent 都使用：

``` python
np.argmax(...)
```

那么它们都倾向返回 action 0。

因此实验开始位置可能出现异常高的 Optimal Action Rate。

这个现象：

$$
\boxed{\text{不是 Agent 瞬间学会了最优动作}}
$$

而是初始化与 Tie-Breaking 共同造成的统计现象。

------------------------------------------------------------------------

# 36. 当前算法之间的关系

目前已经学习了三种不同的探索/估计思路。

## ε-Greedy

核心：

$$
\boxed{\text{用固定概率进行随机探索}}
$$

优点：

-   简单；
-   能持续探索。

缺点：

-   探索动作是随机选的；
-   即使某些动作已经明显很差，探索时仍可能选择它。

## Optimistic Initial Values

核心：

$$
\boxed{\text{通过高估未知动作诱导探索}}
$$

优点：

-   不需要额外随机探索；
-   在平稳问题早期可以有效尝试动作。

缺点：

-   主要在早期发挥作用；
-   初始乐观被消耗后，不容易应对后续环境变化。

## Constant Step Size

它本身主要不是动作选择策略，而是：

$$
\boxed{\text{动作价值估计的更新方式}}
$$

核心：

> 让近期经验持续具有较高权重，从而适应非平稳环境。

不要把：

-   ε-greedy；
-   optimistic initialization；
-   constant step size；

误认为三个完全同类型的算法。

前两个主要影响"怎么选择动作"，固定步长主要影响"怎么更新动作价值"。

# 37. 当前数学公式与 Python 代码对应

## 真实动作价值

$$
q_*(a)
$$

``` python
true_values[action]
```

## 动作价值估计

$$
Q_t(a)
$$

``` python
q_values[action]
```

## 动作访问次数

$$
N(a)
$$

``` python
action_counts[action]
```

## greedy

$$
A_t=\arg\max_aQ_t(a)
$$

``` python
action = np.argmax(q_values)
```

## ε-greedy

$$
A_t=
\begin{cases}
\text{Random Action},&\text{概率 }\epsilon\\
\arg\max_aQ_t(a),&\text{概率 }1-\epsilon
\end{cases}
$$

``` python
if np.random.random() < epsilon:
    action = np.random.randint(k)
else:
    action = np.argmax(q_values)
```

## Sample Average

$$
Q(a)\leftarrow Q(a)+\frac1{N(a)}[R-Q(a)]
$$

``` python
action_counts[action] += 1
q_values[action] += (
    reward - q_values[action]
) / action_counts[action]
```

## Constant Step Size

$$
Q(a)\leftarrow Q(a)+\alpha[R-Q(a)]
$$

``` python
q_values[action] += alpha * (
    reward - q_values[action]
)
```

## Random Walk

$$
q_{*,t+1}(a)=q_{*,t}(a)+\eta_t(a)
$$

``` python
true_values += np.random.normal(
    0.0,
    random_walk_std,
    size=k,
)
```

# 40. 下一步：置信上界 UCB

下一步学习：

**置信上界（Upper Confidence Bound, UCB）**

ε-greedy 的探索方式是：

> 决定探索之后，随机选择一个动作。

这会带来一个问题：

> 如果某些动作已经被尝试很多次，而且基本可以确定它们很差，为什么探索时还要随机选择它们？

UCB 将引入一个新的思想：

$$
\boxed{\text{不仅考虑一个动作当前估计有多好，还考虑我们对它有多不确定}}
$$

后续将学习经典形式：

$$
A_t
=
\arg\max_a
\left[
Q_t(a)
+
c\sqrt{\frac{\ln t}{N_t(a)}}
\right]
$$

其中：

$$
Q_t(a)
$$

代表当前价值估计，而：

$$
c\sqrt{\frac{\ln t}{N_t(a)}}
$$

代表探索相关的不确定性奖励。

这部分将在下一阶段从问题动机开始推导，不需要提前记忆公式。
